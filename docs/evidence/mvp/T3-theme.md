## Matriz de contraste / Contrast matrix

Los cocientes se calculan con luminancia relativa WCAG. Texto exige al menos
4.5:1; límites de controles y foco, 3:1. / Ratios use WCAG relative luminance.
Text requires at least 4.5:1; control boundaries and focus require 3:1.

| Modo / Mode | Texto / Text | Control | Foco / Focus |
|---|---:|---:|---:|
| Light | 16.96:1 | 6.15:1 | 6.82:1 |
| Dark | 16.96:1 | 5.72:1 | 9.46:1 |
| High Contrast Light | 21.00:1 | 21.00:1 | 21.00:1 |
| High Contrast Dark | 21.00:1 | 21.00:1 | 19.56:1 |

El foco usa grosor `2 px`. El estado seleccionado dispone del glifo semántico
`SelectedStateGlyph`, por lo que el color no es la única señal. / Focus uses a
`2 px` stroke. Selected state has the semantic `SelectedStateGlyph`, so color
is not the only cue.
